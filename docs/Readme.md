# NeuroScan Documentation

This directory contains research materials, thesis chapters, and related documentation for the NeuroScan project.

## Structure

```
docs/
├── chapters/          # Thesis chapters
│   ├── CHAPTER1.md
│   ├── CHAPTER2.md
│   ├── CHAPTER3.md
│   ├── CHAPTER4.md
│   └── NeuroScan-CHAPTER2.docx
├── figures/           # Diagrams and visualizations
│   ├── figure-2-1-conceptual-framework.svg
│   ├── figure-3-1-process-model.svg
│   ├── figure-3-2-architecture.svg

├── research/          # Research materials and specifications
│   ├── RRL_links.md
│   ├── RRS_links.md
│   ├── reference.md
│   ├── neuroscan-spec.md
│   └── source-grounded-writing-spec.md
├── scripts/           # Build and utility scripts
│   ├── build-preview.sh
│   └── check-layout.py

    └── verified-sources.md
```
